# Монгол хадмал (subtitles)

Энэ хавтсанд кино бүрийн монгол хадмалыг тавина. Player нь дараах **нэрлэх конвенц**-оор
файлыг автоматаар олж, upload хийхгүйгээр видеон дээр гаргана:

```
public/subtitles/{TMDB_MOVIE_ID}-mn.vtt
```

## Жишээ

- Кино ID = `1078605` → `public/subtitles/1078605-mn.vtt`
- URL дээр `/movie/1078605` нээгээд **"Монгол хадмалтай"** таб дарахад автоматаар ачаална.

## Формат

Зөвхөн **WebVTT** (`.vtt`) формат. Эхний мөр заавал `WEBVTT` байх ёстой:

```
WEBVTT

00:00:01.000 --> 00:00:04.000
Эхний өгүүлбэр.

00:00:04.000 --> 00:00:07.000
Дараагийн өгүүлбэр.
```

## .srt файлаас хөрвүүлэх

`.srt` файлтай бол timestamp дахь таслалыг (`,`) цэг (`.`) болгож, эхэнд `WEBVTT` мөр
нэмнэ. Эсвэл player дээрх **"Монгол хадмал оруулах"** товчоор `.srt` шууд оруулбал
автоматаар хөрвүүлнэ.

> Тэмдэглэл: хадмал видеотой синк болохын тулд тухайн видеоны цаг хугацаанд тааруулж
> бичсэн байх шаардлагатай.
